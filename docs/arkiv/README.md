# Historical Documentation Archive

This directory contains historical legacy documents, superseded plans, and
previous task records. They preserve the project's history and describe the
repository as it existed when they were written.

Documents here are not current specifications, implementation guidance, or
active backlogs. Their paths, links, commands, and descriptions may be outdated
or invalid. Do not validate their contents against the current repository or
update them merely to make repository checks pass. The documentation checker
excludes this directory and all its subdirectories.

For current requirements, architecture, and active tasks, start with the
[documentation index](../README.md). Links from current documentation to archive
files are still validated; the archived files' own contents are excluded.
